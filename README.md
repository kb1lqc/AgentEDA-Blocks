# ina229

INA229-based 85 V power, energy and charge monitor with SPI, designed in [Zener](https://docs.pcb.new) with Diode's
`pcb` toolchain.

Components come from [kb1lqc/zener-library](https://github.com/kb1lqc/zener-library): each part has datasheet data
(`component.toml`), datasheet equations (`calc.py`), KiCad files and a generated Zener wrapper with DC rating checks.
The Zener wrappers capture the circuit; the same parts' Python data drives the worst-case analysis in `analysis/`.

## Layout

| Path | What |
|---|---|
| `ina229.zen` | Board entry point (`Board(...)`, 4 layers, linked KiCad schematic) |
| `pcb.toml` | Workspace, board metadata, and tool-managed dependencies |
| `spec.md` | Requirements and open questions; decide here before capturing |
| `modules/` | Hierarchical circuit blocks (create as needed) |
| `analysis/` | Python worst-case / nominal analyses using the library's `lib/` |
| `eda/` | KiCad project, generated by `pcb layout` / `pcb apply` |
| `docs/` | Design notes; `docs/datasheets/` and `docs/vendor/` are git-ignored |

## Setup

```sh
# pcb toolchain 0.4.x: https://docs.pcb.new
git clone https://github.com/kb1lqc/ina229.git
# Python analyses need the library checked out next to this repo, at the version pinned in analysis/_zl.py:
git clone --branch v0.3.0 https://github.com/kb1lqc/zener-library.git zener-library
```

Enable the schematic sync check on commit (once per clone):

```sh
git -C ina229 config core.hooksPath tools/git
```

The `.zen` files are the source of truth for the circuit; review the schematic in KiCad, but make circuit changes in
the `.zen`. `tools/schematic/check_sync.sh` shows whether the KiCad schematic matches the `.zen`.

The library checkout must stay outside this repo: `pcb` rejects any nested `pcb.toml` with a `[workspace]` section,
including in hidden or git-ignored folders. Set `ZENER_LIBRARY` to use a different checkout.

## Use

```sh
pcb build ina229.zen          # evaluate the design and run electrical checks
pcb build -Dwarnings ina229.zen   # treat warnings (UNVERIFIED checks) as errors
pcb layout ina229.zen         # generate / update the KiCad board
pcb bom ina229.zen -f json    # bill of materials
python3 -m analysis.smoke     # confirm the library loads
```

Add a library part by importing its wrapper, then `pcb sync` to record the dependency:

```zen
INA229 = Module("github.com/kb1lqc/zener-library/components/TexasInstruments/INA229AIDGS/INA229AIDGS.zen")
```
